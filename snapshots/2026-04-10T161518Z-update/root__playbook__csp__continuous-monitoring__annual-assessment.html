# Annual Assessments CA-2 requires annual independent assessment. This guidance assumes CSP has transitioned to FedRAMP Rev5 baselines (Rev4 CSOs must undergo full new assessment). ## Annual Assessment Process Steps 1. Develop Assessment Schedule 2. Review and Update Documentation (SSP and appendices; use latest templates) 3. Incident Response and Contingency Testing (must test IRP and CP annually) 4. Define Assessment Scope using FedRAMP Annual Assessment Control Selection Worksheet: core controls, CSP-selected controls for system changes, POA&M validations, N/A controls, 3-year periodic controls 5. Develop SAP 6. Brief Agency Customers on Assessment Plan (during monthly collaborative ConMon if multiple agencies) 7. Conduct Assessment and Develop SAR (using FedRAMP SAR template, RET, and appropriate SRTM) 8. Complete POA&M (document residual risks and remediation plan)
