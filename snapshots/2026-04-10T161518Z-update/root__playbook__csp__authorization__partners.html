# Partners in the Authorization Process ## FedRAMP Stewards of FedRAMP authorization process; enables reuse via USDA Connect.gov secure repository (LI-SaaS, Low, Moderate) or CSP's own repository (High). Access via FedRAMP Package Access Request Form. ## Federal Agencies Review CSP-developed security packages. Agency AO issues ATO letter (risk-based decision). Each agency must issue its own ATO/ATU and perform ConMon oversight. Initial ATO is NOT a government-wide risk acceptance. ## Third Party Assessment Organizations (3PAOs) Perform initial and periodic assessments. CSPs may use FedRAMP recognized 3PAOs (see Marketplace) or agency IV&V team (AO must attest to independence). 3PAOs must use FedRAMP-provided templates.
