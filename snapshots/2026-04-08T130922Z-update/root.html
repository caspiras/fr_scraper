# FedRAMP Rev5 Documentation and Playbooks [Getting Started with FedRAMP Rev5](https://www.fedramp.gov/docs/rev5/playbook/csp/authorization/getting-started/) for cloud service providers [Rev5 Authorization Playbook](https://www.fedramp.gov/docs/rev5/playbook/csp/authorization/what/) for cloud service providers [Rev5 Continuous Monitoring Playbook](https://www.fedramp.gov/docs/rev5/playbook/csp/continuous-monitoring/intro/) for cloud service providers [Rev5 Agency Authorization Playbook](https://www.fedramp.gov/docs/rev5/playbook/agency/authorization/) for federal agencies [Balance Improvement Releases](https://www.fedramp.gov/docs/rev5/balance) for cloud service providers and federal agencies bring modern requirements and recommendations from [FedRAMP 20x](https://www.fedramp.gov/docs/20x/) to the legacy FedRAMP Rev5 process; most are optional but some are mandatory.
