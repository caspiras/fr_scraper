# Cloud Service Providers What is the difference between Rev5 and 20x? FedRAMP Rev5 Agency Authorizations (aka "sponsored authorization") are the only widely available path to FedRAMP authorization at this time. FedRAMP 20x is a newer modern path under development and not available to the public at this time. See FedRAMP.gov/20x.
