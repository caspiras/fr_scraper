# The FedRAMP Rev5 Agency Authorization Path Same process as Agency Authorization Playbook, from CSP's perspective with additional CSP-specific steps. ## Phase 1: Preparation - FedRAMP Ready (optional but recommended): Readiness Assessment by 3PAO; RAR documents security capability - Pre-Authorization: Partnership Establishment, Authorization Planning (WBS + IPR to intake@fedramp.gov), Kickoff Meeting ## Phase 2: Authorization - Full Security Assessment: 3PAO develops SAP, tests system, develops SAR; CSP develops POA&M; SAR debrief presentation - Agency Authorization Process: Agency reviews deliverables; AO issues ATO letter; FedRAMP quality and risk review; FedRAMP Authorized designation ## Phase 3: Continuous Monitoring CSP continues providing monthly ConMon deliverables. CSPs with multiple agency customers implement Collaborative ConMon. Annual 3PAO security assessment required.
