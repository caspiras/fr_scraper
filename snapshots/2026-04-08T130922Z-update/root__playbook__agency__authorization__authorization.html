# Authorization (Agency Playbook) ## Full Security Assessment 3PAO performs independent security assessment. Tests and validates CSP's implementation of security controls, validates vulnerability scans, performs penetration testing. Develops SAR with authorization recommendation. CSP develops POA&M based on SAR findings. ## Agency Authorization Process 1. Agency Review of Security Authorization Package (SSP/appendices, SAP, SAR, POA&M) 2. SAR Debrief - 3PAO presents assessment results; CSP presents remediation plan; agency describes remaining milestones 3. Remediation - CSP/3PAO address documentation gaps; delta testing if needed 4. Agency Final Review and ATO - AO issues ATO letter to CSP and ato-letter@fedramp.gov 5. FedRAMP Review - Quality and risk review to determine suitability for government-wide reuse; FedRAMP Authorized designation granted
