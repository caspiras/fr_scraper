# Security Assessment Report (SAR) Documents results of security assessment; developed by 3PAO. Goes through multiple iterations as CSP remediates/mitigates risks. Components: SAR*, Appendix A: RET*, Appendix B: SRTM Workbook*, Appendix C: Vulnerability Scan Results, Appendix D: Documentation Review Findings, Appendix E: Auxiliary Documents, Appendix F: Penetration Test Report, Assessment Evidence (* = must use FedRAMP template) ## Things to Consider - Did 3PAO use current FedRAMP template (SAR, RET, SRTM)? - Verify SRTM "Other than Satisfied" controls are documented in RET (or in "Risks Corrected During Testing" tab) - Did 3PAO adequately describe mitigating factors for risk adjustments? - Did 3PAO adequately describe rationale for operational requirements? - Is executive summary consistent with RET? - Did 3PAO attest to SAR accuracy and provide authorization recommendation?
