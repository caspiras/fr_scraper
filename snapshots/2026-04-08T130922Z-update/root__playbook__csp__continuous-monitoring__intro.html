# Introduction (Continuous Monitoring Playbook) This FedRAMP Continuous Monitoring Playbook provides overview of Rev5 ConMon requirements, activities, guidance, and best practices. Applies to CSOs authorized via legacy JAB path and current Rev5 Agency Authorization path. Consolidates the following (all now rescinded/replaced): - FedRAMP Continuous Monitoring Strategy Guide v3.2 (2018) - FedRAMP Vulnerability Scanning Requirements v3.0 (2024) - FedRAMP Vulnerability Scanning Requirements for Containers v1.0 (2021) - FedRAMP Guide for Determining Eligibility and Requirements for Sampling v1.0 (2018) - Vulnerability Scanning FAQ (2025) - FedRAMP Annual Assessment Guidance v3.0 (2024) - FedRAMP Significant Change Policies and Procedures v1.0 (2018) - FedRAMP Incident Communications Procedures v5.0 (2024) - FedRAMP Collaborative ConMon Quick Guide (2023) - FedRAMP Continuous Monitoring Performance Management Guide v3.0 (2023) Note: Many requirements have optional alternatives via Balance Improvement Releases.
