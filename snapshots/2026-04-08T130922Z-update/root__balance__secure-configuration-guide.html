# Secure Configuration Guide Effective Date(s): Required (Wide Release) beginning 2026-03-01. Applies to all FedRAMP Rev5 cloud services (Authorized, In Process, FedRAMP Ready). Authority: Executive Order 14144, as amended by Executive Order 14306 (dated 2025-06-11). Mandatory enforcement timeline: - 2026-03-01: Public notification of non-compliance begins - 2026-05-01: Mandatory Corrective Action Plan for Authorized cloud services - 2026-07-01: Complete removal from FedRAMP Marketplace + ban on relisting for three months ## General Provider Responsibilities - SCG-CSO-RSC: Providers MUST create, maintain, and make available a Secure Configuration Guide including: Required: instructions for securely accessing/configuring/operating top-level administrative accounts; Required: explanations of security-related settings for top-level admin accounts and their security implications; Recommended: explanations for privileged accounts. - SCG-CSO-AUP: Providers MUST include instructions in the authorization package on how to obtain and use the Secure Configuration Guide. - SCG-CSO-PUB: Providers SHOULD make the Secure Configuration Guide publicly available. - SCG-CSO-SDF: Providers SHOULD set all settings to recommended secure defaults when initially provisioned. ## Enhanced Capabilities - SCG-ENH-CMP: Providers SHOULD offer capability to compare current settings to recommended secure defaults. - SCG-ENH-EXP: Providers SHOULD offer capability to export all security settings in machine-readable format. - SCG-ENH-API: Providers SHOULD offer capability to view and adjust security settings via an API. - SCG-ENH-MRG: Providers SHOULD provide the Secure Configuration Guide in machine-readable format. - SCG-ENH-VRH: Providers SHOULD provide versioning and release history for recommended secure defaults.
