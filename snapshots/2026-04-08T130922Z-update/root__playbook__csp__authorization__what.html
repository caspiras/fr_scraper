# What's in an Authorization Package A FedRAMP authorization package documents the security and risk posture for a CSP's CSO. ## Required Components - System Security Plan (SSP) and appendices A-Q - Security Assessment Plan (SAP) and appendices A-D - Security Assessment Report (SAR) and appendices A-F - Plan of Action & Milestones (POA&M) (SSP Appendix O) - Signed federal agency Authority to Operate (ATO) Required formats: Microsoft Word and Excel. Some must use FedRAMP-provided templates. Submit FedRAMP Initial Authorization Package Checklist (intake@fedramp.gov). Note: CSPs and 3PAOs may NOT alter or remove content in SSP/SAP/SAR templates. Should remove italicized instructional text before final submission.
