# FedRAMP Sponsoring Initial Authorization - Content Summary ## Page Overview This documentation page explains how federal agencies can sponsor initial FedRAMP authorizations for Cloud Service Providers (CSPs) that aren't yet FedRAMP authorized. ## Key Content Sections **Main Purpose:** "Federal agencies can partner with a Cloud Service Provider (CSP) for an initial FedRAMP authorization if they would like to use a CSO that is not currently FedRAMP Authorized." ## Common Questions Addressed The page references seven frequently asked questions answered in FedRAMP's Help Center: 1. What it means to be an initial agency partner 2. Additional effort requirements for initial authorizing agencies 3. Continuous Monitoring (ConMon) oversight responsibilities 4. FedRAMP acceptance of ATO and ATU documents 5. Procedures when an agency stops using the service 6. Outcomes when a CSO loses all agency customers 7. Whether to use FedRAMP for private cloud deployments ## Navigation Structure - Links to related sections: The FedRAMP Marketplace, Liaison Program, Preparation, Authorization, and Continuous Monitoring - Contact point: intake@fedramp.gov for additional questions - Recommendation to consult agency FedRAMP liaisons first ## Document Organization The page is part of FedRAMP Rev5 documentation, specifically the Agencies section within the authorization playbook.
