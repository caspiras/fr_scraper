# Security Assessment Report (SAR) - FedRAMP Documentation ## Overview The Security Assessment Report documents the results of evaluating a Cloud Service Offering's implementation and compliance with FedRAMP baseline security controls. As stated in the documentation: "The purpose of the security assessment is to evaluate the CSO's implementation of, and compliance with, FedRAMP baseline security controls." ## Key Components The SAR submission must include: - **Main SAR Document** (FedRAMP template required) - **Appendix A:** Risk Exposure Table (RET) — template required - **Appendix B:** Security Requirements Traceability Matrix (SRTM) Workbook — template required - **Appendix C:** Vulnerability Scan Results - **Appendix D:** Documentation Review Findings - **Appendix E:** Auxiliary Documents - **Appendix F:** Penetration Test Report - Supporting evidence from the assessment ## Critical Review Areas CSPs should verify several elements before SAR delivery: 1. **Template Compliance:** Confirm the 3PAO used current FedRAMP-provided templates 2. **Appendix Completeness:** Ensure all required sections are included 3. **Finding Documentation:** Cross-reference SRTM findings against the RET 4. **Risk Descriptions:** Verify mitigating factors are thoroughly explained, especially for High-rated risks 5. **Executive Summary Alignment:** Confirm the summary in Section 2 matches the RET data 6. **Attestation:** Verify the 3PAO provided accuracy attestation and authorization recommendation The assessment team (3PAO) typically iterates the SAR multiple times to reflect risks remediated or mitigated during testing.
