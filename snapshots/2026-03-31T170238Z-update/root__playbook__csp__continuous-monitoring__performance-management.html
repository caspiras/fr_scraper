# ConMon Performance Management - FedRAMP Documentation ## Overview This FedRAMP documentation page addresses escalation procedures when Cloud Service Providers (CSPs) fail to meet Continuous Monitoring (ConMon) requirements for authorized Cloud Service Offerings (CSOs). ## Key Sections ### Performance Management for Ongoing Authorization The page establishes that each authorizing agency must independently oversee ConMon activities, including: - Monthly Plans of Action & Milestones (POA&M) review - Deviation request approval - Significant change request approval - Annual assessment result review ### Escalation Levels The document outlines four escalation tiers: 1. **Detailed Finding Review (DFR)** - Initial request to assess and remedy deficiencies 2. **Corrective Action Plan (CAP)** - Formal root-cause analysis and remediation plan required 3. **Suspension** - Temporary ATO suspension pending resolution 4. **Revocation** - Permanent ATO termination with data migration required ### Deficiency Triggers The guidance provides specific performance metrics across three areas: **Operational Visibility** includes vulnerability escalation thresholds (20% increase from baseline), late remediation triggers, and late deliverable submissions. **Change Control** addresses insufficient change notice periods and undocumented changes. **Incident Response** covers late notifications, CISA Emergency Directive non-compliance, and recurring incident patterns. ### FedRAMP's Role FedRAMP monitors agency packages to verify annual assessment completion, confirm continued authorization recommendations, and maintain accurate marketplace status.
