# Annual Assessments - FedRAMP Documentation ## Overview This FedRAMP documentation page explains the annual assessment process required under security control CA-2. The guidance covers assessments for Cloud Service Providers (CSPs) that have transitioned to FedRAMP Rev 5 baselines. ## Key Process Steps The annual assessment includes eight major phases: 1. **Assessment Schedule Development** - 3PAOs typically create templates incorporating major milestones and resource allocation for technical and quality assurance reviews. 2. **Documentation Review** - CSPs must annually review and update System Security Plans (SSP) and appendices to reflect system changes and procedural updates. 3. **Testing Requirements** - CSPs must conduct annual testing of Incident Response Plans and Contingency Plans; failure to complete this testing can delay assessments. 4. **Scope Definition** - Using the "FedRAMP Annual Assessment Control Selection Worksheet," assessors and CSPs collaboratively determine scope, including: - Core FedRAMP-selected controls - Controls addressing system changes - Validation of closed and vendor-dependent POA&Ms - Controls not assessed within three years 5. **Security Assessment Plan** - Assessors prepare detailed testing procedures and methodologies. 6. **Agency Briefing** - CSPs and assessors brief agency customers on plans, scope, and schedules. 7. **Assessment Execution** - Assessors conduct testing and develop Security Assessment Reports using prescribed templates. 8. **POA&M Completion** - CSPs document residual risks and remediation plans using FedRAMP templates. The page emphasizes using current templates and building adequate time for remediation activities into assessment schedules.
