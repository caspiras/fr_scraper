# FedRAMP Cloud Service Providers Documentation ## Key Distinctions Between Authorization Paths The page clarifies the primary difference between two FedRAMP authorization approaches: **FedRAMP Rev5** is described as "the only widely available path to FedRAMP authorization at this time." This pathway involves agency-sponsored authorizations and represents the current standard for cloud service providers seeking federal compliance. **FedRAMP 20x** is characterized as "a newer modern path that is designed to be more appropriate for cloud-native systems that rely on modern engineering and security principles." However, this path "is under development and is not available to the public at this time." ## Available Resources for CSPs The documentation provides three primary playbooks for organizations pursuing Rev5 authorization: 1. Getting Started with FedRAMP Rev5 2. Rev5 Authorization Playbook (covering authorization packages, roles, security plans, and assessment documentation) 3. Rev5 Continuous Monitoring Playbook (addressing monitoring expectations and incident management) ## Navigation Structure The site organizes information into broader categories including Authority & Responsibility, FedRAMP 20x content, agency-specific guidance, and Balance Improvement Releases with both mandatory and optional elements for Rev5 compliance. For current FedRAMP 20x status and development timelines, the documentation directs readers to FedRAMP.gov/20x.
