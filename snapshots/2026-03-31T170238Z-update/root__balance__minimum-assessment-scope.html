# Minimum Assessment Scope - FedRAMP Documentation ## Overview The Minimum Assessment Scope (MAS) is an optional process for FedRAMP Rev5 authorized providers or those seeking authorization. It allows cloud service providers to narrowly define information resource boundaries while maintaining comprehensive security coverage. **Effective Date:** Optional wide release beginning January 12, 2026 ## Key Requirements Providers adopting MAS must: - Identify information resources likely to handle federal customer data or impact its confidentiality, integrity, or availability - Document information flows and security objectives for all resources - Address third-party information resources by explaining their usage, justification, mitigation measures, and compensating controls - Include metadata about federal customer data within the assessment scope - Notify FedRAMP via email when transitioning from traditional boundaries to MAS - Follow the Significant Change Request process for any boundary transitions - Have changes assessed by FedRAMP-recognized assessors ## Authority The guidance derives from OMB Circular A-130, NIST SP 800-37 Rev. 2, and the FedRAMP Authorization Act, which grants GSA responsibility to "establish and update guidance on the boundaries of FedRAMP authorization packages." ## Core Principle Overly broad application boundaries complicate assessments by including components unlikely to affect data protection. MAS provides a framework to define focused yet complete assessment scopes.
