# FedRAMP Security Inbox - Content Summary ## Overview The FedRAMP Security Inbox is a mandatory requirement for all FedRAMP Rev5 cloud services, effective January 5, 2026. This document establishes communication protocols between FedRAMP and cloud service providers for critical security matters. ## Key Requirements **FedRAMP's Responsibilities:** - Send messages from verified @fedramp.gov or @gsa.gov addresses with proper email authentication (SPF, DKIM, DMARC) - Use criticality designators: "Emergency," "Emergency Test," or "Important" - Send Emergency/Emergency Test messages from fedramp_security@gsa.gov or fedramp_security@fedramp.gov - Provide at least 10 business days' public notice before Emergency Tests - Specify required actions and timeframes clearly - Default reaction timeframes: 12 hours (High Impact), 2 business days (Moderate), 3 business days (Low) - Explain potential corrective actions **Provider Responsibilities:** - Maintain a dedicated FedRAMP Security Inbox email address - Immediately notify FedRAMP (info@fedramp.gov) of any email address changes - Trust all @fedramp.gov and @gsa.gov emails as legitimate FedRAMP communications - Receive emails without disruption or additional verification steps - Complete required actions within specified timeframes - Route Emergency messages to senior security officials - Acknowledge receipt of FedRAMP messages (recommended) ## Enforcement Timeline - January 5, 2026: Requirements become effective - March 1, 2026: Public marketplace notification of non-compliance begins - May 1, 2026: Removal from FedRAMP Marketplace for violations - July 1, 2026: Three-month relisting ban implemented
