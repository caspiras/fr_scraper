# Security Assessment Plan (SAP) - FedRAMP Documentation ## Overview The Security Assessment Plan is a critical document developed by Third Party Assessors (3PAOs) that outlines how a Cloud Service Offering will be evaluated. As one source explains, "The SAP describes the scope, methodology, test plan, and rules of engagement for the assessment of a CSO." Both the CSP and 3PAO must formally sign this document, signifying their mutual understanding and commitment to the assessment approach and engagement protocols. ## Required Components The SAP package includes several mandatory elements: - The SAP itself (must use FedRAMP-provided template) - Appendix A: Security Controls Selection Worksheet - Appendix B: Sampling Methodology - Appendix C: Penetration Testing Plan and Methodology - Appendix D: Significant Change Request Documentation ## Key Review Considerations When evaluating an SAP, CSPs should verify: 1. **Template Compliance**: Confirm the 3PAO used the official FedRAMP template 2. **Completeness**: Ensure all required artifacts are included 3. **Scope Accuracy**: Verify coverage of all system services, components, and devices within the authorization boundary 4. **Sampling Documentation**: Confirm sampling methodologies align with FedRAMP vulnerability scanning requirements 5. **Schedule Alignment**: Review that testing timelines match agreements 6. **Penetration Testing**: Validate consistency with FedRAMP's penetration test guidance CSPs should thoroughly review the SAP and collaborate with the 3PAO to make necessary adjustments before assessment activities commence.
