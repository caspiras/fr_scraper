# FedRAMP Continuous Monitoring Introduction ## Overview This page introduces FedRAMP's Continuous Monitoring (ConMon) playbook for Rev 5 authorized cloud service offerings. The resource consolidates multiple previously standalone documents into a single comprehensive guide. ## Key Content **Purpose**: The playbook delivers "an overview of FedRAMP Rev 5 continuous monitoring requirements and activities, along with guidance and best practices." **Scope**: Applies to cloud services authorized through both the legacy JAB path and current Rev5 Agency Authorization approach. ## Consolidated Documents The playbook integrates guidance from ten prior publications, including: - Continuous Monitoring Strategy Guide (v3.2, 2018) - Vulnerability Scanning Requirements (v3.0, 2024) - Annual Assessment Guidance (v3.0, 2024) - Incident Communications Procedures (v5.0, 2024) - Performance Management Guide (v3.0, 2023) ## Important Notice The page emphasizes that "all of the materials mentioned above should be considered rescinded and replaced; they are outdated and must not be used." Organizations should reference this consolidated playbook rather than earlier standalone documents. ## Navigation Context This introduction precedes sections covering expectations, vulnerability scanning, annual assessments, significant changes, incident communication, collaborative monitoring, and performance management.
