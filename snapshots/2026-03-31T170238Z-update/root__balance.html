# Rev5 Balance Improvement Releases - FedRAMP Documentation ## Overview FedRAMP is integrating modernization improvements from FedRAMP 20x into Rev5 while maintaining stability for existing authorized providers. The integration balances "modernization with stability" to minimize disruption. ## Mandatory Requirements for Rev5 These policies are **required** for all Rev5 cloud service providers: | Policy | Effective Date | |--------|----------------| | FedRAMP Security Inbox | January 5, 2026 | | Secure Configuration Guide | March 1, 2026 | All requirements and recommendations must be addressed by these dates. ## Optional Enhancements for Rev5 Providers can voluntarily adopt these policies through Rev5-specific processes. Implementation only applies to providers choosing adoption, though FedRAMP must be notified beforehand. ### Wide Releases (Available Now) - **Minimum Assessment Scope** - Optional since January 12, 2026 - **Significant Change Notifications** - Optional beginning February 27, 2026 ### Beta Programs (February 2 - May 22, 2026) - Authorization Data Sharing - Vulnerability Detection and Response - Collaborative Continuous Monitoring ## Key Terminology Notes FedRAMP uses RFC 2119 capitalized keywords (MUST, SHOULD, MAY, etc.) with specific meanings. The term "SHOULD" indicates recommendations requiring documented justification if not implemented, as providers may be assessed as less secure otherwise.
