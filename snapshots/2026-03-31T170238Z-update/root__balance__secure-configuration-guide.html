# FedRAMP Secure Configuration Guide Summary ## Overview This FedRAMP documentation outlines mandatory requirements for cloud service providers to create and maintain Secure Configuration Guides (SCGs) beginning March 1, 2026. ## Key Requirements **Mandatory Provider Responsibilities:** 1. **Configuration Guidance**: Providers must create guides explaining how to "securely access, configure, operate, and decommission top-level administrative accounts." 2. **Security Documentation**: The guide must explain "security-related settings that can be operated only by top-level administrative accounts and their security implications." 3. **Privileged Account Guidance**: Recommended documentation for "security-related settings that can be operated only by privileged accounts." 4. **Access Instructions**: Providers must include instructions in authorization packages explaining how to obtain and use the SCG. ## Enhanced Capabilities (Recommended) - **Comparison tools** to evaluate current settings against secure defaults - **Export functionality** for security settings in machine-readable formats - **API access** to view and adjust security settings - **Machine-readable guidance** for customer and third-party tool compatibility - **Version tracking** and release history documentation ## Enforcement Timeline - **March 1, 2026**: Enforcement begins; non-compliance triggers corrective action - **May 1, 2026**: Authorized services face public remediation notices and mandatory corrective action plans - **July 1, 2026**: All non-compliant services removed from FedRAMP Marketplace with three-month relisting ban
