# What's in an Authorization Package - FedRAMP Documentation ## Overview A FedRAMP authorization package documents security and risk details for a Cloud Service Offering (CSO). It serves as a comprehensive security blueprint containing multiple required documents and appendices that federal agencies use to authorize cloud services for government use. ## Core Components The authorization package includes: - **System Security Plan (SSP)** with appendices A-Q, defining the CSO's authorization boundary and describing security controls protecting confidentiality, integrity, and availability - **Security Assessment Plan (SAP)** with appendices A-D - **Security Assessment Report (SAR)** with appendices A-F - **Plan of Action & Milestones (POA&M)** as SSP Appendix O - **Signed Authority to Operate (ATO)** from a federal agency ## Required Appendices Notable SSP appendices include Appendix C (Security Policies and Procedures) and Appendix I (Incident Response Plan), among others. ## Submission Requirements CSPs must submit documents in designated formats, primarily Microsoft Word and Excel. The FedRAMP Initial Authorization Package Checklist must accompany submissions. While template content cannot be altered, instructional text in italics should be removed before final submission. Agency-specific requirements exceeding FedRAMP baseline standards must be documented in an SSP appendix.
