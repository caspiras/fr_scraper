# Secure Configuration Guide Effective Date(s): Required (Wide Release) beginning 2026-03-01. Applies after March 1, 2026 to all FedRAMP Rev5 cloud services, including Authorized, In Process, and FedRAMP Ready. Background: References Executive Order 14144, as amended by Executive Order 14306 (2025-06-11) Sustaining Select Efforts to Strengthen the Nation's Cybersecurity. Mandatory Adoption enforcement timeline: - 2026-03-01: Corrective action includes public notification of non-compliance - 2026-05-01: Corrective action includes public notification of remediation and mandatory Corrective Action Plan - 2026-07-01: Corrective action includes complete removal from FedRAMP Marketplace and ban on relisting for three months ## General Provider Responsibilities - SCG-CSO-RSC: Recommended Secure Configuration (MUST create, maintain, and make available) - SCG-CSO-AUP: Use Instructions (MUST include in authorization package) - SCG-CSO-PUB: Public Guidance (SHOULD make publicly available) - SCG-CSO-SDF: Secure Defaults (SHOULD set recommended secure defaults) ## Enhanced Capabilities - SCG-ENH-CMP: Comparison Capability (SHOULD offer) - SCG-ENH-EXP: Export Capability (SHOULD offer in machine-readable format) - SCG-ENH-API: API Capability (SHOULD offer) - SCG-ENH-MRG: Machine-Readable Guidance (SHOULD provide) - SCG-ENH-VRH: Versioning and Release History (SHOULD provide)
